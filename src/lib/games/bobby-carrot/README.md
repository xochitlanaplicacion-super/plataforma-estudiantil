# Bobby Carrot en el repertorio docente

La plataforma sirve aquí la edición web autocontenida del proyecto `BobbyCarrotRemastered` mediante una ruta autenticada para profesores. El ejecutable nativo y el código Odin no se distribuyen en la plataforma.

Fuente revisada: <https://github.com/ftphikari/BobbyCarrotRemastered>

El repositorio fuente no incluye una licencia general para el juego ni para su arte; la licencia BSD-2-Clause que contiene corresponde únicamente a la dependencia interna `pdb`. Mantener esta actividad restringida al uso educativo autorizado y confirmar los permisos del autor antes de una distribución pública.
